# Tudatos Márka Kör - Plugin

A Tudatos Márka Kör márkaalap-fájljai:

- `soul.md` - a márka lelke és identitása
- `voice.md` - márkahang és hangnem
- `audience.md` - célközönség (egyelőre helykitöltő megfogalmazásokkal)
- `tudatos-marka-kor-design-system.md` - design system (színek, tipográfia, komponensek)
